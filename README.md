# Tratta

Gioco browser: strada infinita, slalom nel traffico, consegne e officina.

- Apri `index.html` (serve rete per Three.js dal CDN).
- Auto o moto, due lavori: consegna espressa (4 km in 80s) e slalom pulito (28 sorpassi).
- Officina: filtro, scarico, centralina, turbo, gomme, assetto, freni, alleggerimento.
- La volante non può sbattere: sposta il giocatore, non conta come urto.
- Soldi e modifiche in localStorage (`tratta-cash`, `tratta-mods`).
